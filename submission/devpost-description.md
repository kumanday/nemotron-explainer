# Project description draft

Nemotron Explainer is a Pi workflow in development for producing mixed-media
explainers with Nemotron 3.5 Super VL on Nebius Token Factory, Media Tooling,
HyperFrames and TTV Pipeline.

The prototype demonstrates authenticated model/tool/image interaction, narration,
HTML composition and a local encode. The planned submission adds real generated
footage, explanatory motion graphics and visual revision of the encoded result.
The final submission video is intended to be made by the same workflow.

Track: Best Apps and Agents. Prepare final claims and public links from the
accepted versioned artifact and its verified receipts. Production is incomplete;
publication awaits the owner's authorization.
