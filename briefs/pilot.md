# Pilot brief: workflow self-demonstration (10–20 s)

## Subject
Show the nemotron-explainer workflow operating on itself: brief → model run → storyboard
→ motion graphics → visual review → render.

## Format
- English, 1920×1080, 30 fps, 10–20 seconds.
- ElevenLabs eleven_v4 narration (configured voice), no music/SFX.
- Motion graphics only in the pilot; generated footage is reserved for the submission film.
- Real artifacts: this brief, a terminal capture of the run, inspected frames, the render.

## Beats
1. Hook: title card with the self-authorship premise.
2. Input: this brief shown on screen next to a real Pi/Nebius run capture.
3. Build: storyboard cells and composition source.
4. Review: an inspected frame with one evidenced revision.
5. Claim: "This video was created using this tool."

## Constraint
Every on-screen element must trace to an actual artifact in this project; no placeholder
media, no invented run output.
