# Tool and model observations

Pi's native session confirms that edit calls initially used the wrong argument
shape, then recovered with `edits[].oldText` and `edits[].newText`. Nebius rejects
more than eight images across replayed history; the project adapter now sends
the newest eight and preserves the complete native session.

The model loaded the high-level media and HyperFrames skills but skipped the
creative house-style, detailed animation guidance and mandatory storyboard/spec.
It generated a mostly static text-and-screenshot film and declared completion
without executing TTV. Model quality and capability remain to be established by
the short mixed-media proof in RECOVER.md.

HyperFrames lint/runtime checks cover technical properties. Product acceptance
also needs real generated footage, meaningful motion, readable composition and
critical review of timecoded encoded frames. Media Tooling narration metadata
includes tail holds; use the documented timing sync or account for those holds
explicitly. Track unknown charges separately from known amounts and quotes.
