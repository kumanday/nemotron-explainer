# Numerical design spec — self-demo-v2

GOAL: The viewer understands that a short Markdown brief becomes a narrated
mixed-media film through this same Nemotron + Media Tooling + TTV +
HyperFrames workflow, with one real TTV-generated clip and explanatory motion
sequences that develop across the narrated beats.

OUTPUT: HyperFrames, 1920×1080, 30 fps, H.264 MP4, 91.36 s.

LOOK:
- Ground: #0b0f19 near-black dark flat solid. No full-screen linear gradients.
- Accent: #22d3ee at full saturation on focal elements; 15-25% for glows.
- Ink: #f8fafc for readable text.
- Display face: Inter 700-900. Chapter lines 86-96 px. Body 34-44 px.
- Monospace: Space Mono 42 px for the input brief.
- One hero move per shot; secondary moves 50-70% as far, start 100-200 ms later.
- No fade-and-slide-up for every element; land titles dead still.

SHOTS (frame ranges at 30 fps):
- hook: 0-248 frames (0-8.28 s): kinetic title word by word.
- input: 248-540 frames (8.28-18.0 s): Markdown brief lines appear one at a time.
- build: 540-851 frames (18.0-28.36 s): TTV workbench clip then pipeline diagram grows node by node.
- revise: 851-1205 frames (28.36-40.16 s): before/after captures.
- result: 1205-1664 frames (40.16-55.48 s): bar grows, 91 s numeral lands, passage holds.
- howmade: 1664-2606 frames (55.48-86.88 s): component credits one per beat.
- claim: 2606-2741 frames (86.88-91.36 s): claim line holds to end.

BANNED: dark void with small floating elements; glow/bloom/neon as decoration;
purple-blue gradients; glass cards; everything centred; everything fading in at
once; text that moves while read; corner labels; three cards in a row; logo
docked in a corner.
